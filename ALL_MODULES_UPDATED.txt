HOW IT WORKS:
================================================================================

When you upload a DOCX or PDF file:
1. Shows: "Extracting text from DOCX file..."
2. Sends file to /upload_handler.php
3. Server extracts text using TextExtractor.php
4. Returns extracted text with word count
5. Smart detection analyzes the text
6. Form fields auto-fill with detected data
7. Shows: "Successfully extracted X words from filename.docx"
