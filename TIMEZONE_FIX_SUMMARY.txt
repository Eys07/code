========================================
ACTIVITY LOG TIMEZONE FIX - QUICK SUMMARY
========================================

PROBLEM:
--------
Activity log times were showing 8 HOURS BEHIND actual Philippine time.
Example: Event at 10:00 AM showed as 02:00 AM

ROOT CAUSE:
-----------
Both PHP and Database were using UTC timezone instead of Asia/Manila (UTC+8)

SOLUTION:
---------
1. Set PHP timezone to Asia/Manila in config.php
2. Set Database session timezone to +08:00 in config.php
3. Created helper function formatPhilippineTime() in logger.php
4. Updated activity_log.php to use the helper function

  - Added: $conn->query("SET time_zone = '+08:00'");

✓ /home/delfin/code/clone/eFIND/admin/includes/logger.php
